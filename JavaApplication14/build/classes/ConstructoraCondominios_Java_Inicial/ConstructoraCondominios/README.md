# ConstructoraCondominios - estructura inicial

Proyecto Java inicial con paquetes modelo, gestion, interfaz y util.

## Cómo abrir
1. Cree un proyecto Java en NetBeans/IntelliJ/Eclipse.
2. Copie la carpeta `src` dentro del proyecto (o abra el proyecto si su IDE lo permite).
3. Ejecute `Main.java`.

## Importante
- Este entregable contiene declaraciones y atributos iniciales; no implementa todavía las reglas de negocio.
- Los arreglos son estructuras en memoria, de acuerdo con las restricciones del enunciado.
- Las ventanas Swing son esqueletos: todavía falta diseñar formularios y conectar botones.
- Ajusten los tamaños de los arreglos según las necesidades del equipo.
- Se usaron cadenas para fechas para mantener el esqueleto sencillo; pueden migrar a LocalDate si fue visto y permitido en clase.
